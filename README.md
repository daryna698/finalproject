# Новорічний ярмарок — 3D (Three.js)

Інтерактивна сцена: ялинка, ярмаркові будиночки, ковзанка з ковзанярами, карусель, сніг, північне сяйво.

## Запуск
```
npm install
npm run dev
```

## Збірка
```
npm run build      # результат у папці dist
npm run preview
```

## Публікація
- **GitHub Pages:** `npm run deploy` → Settings → Pages → Branch `gh-pages` / root
- **Vercel:** імпортуйте репозиторій, Framework = Vite (build `npm run build`, output `dist`)

## Керування
- Клік — кинути сніжку (фізика), мишка — камера
- Панель праворуч: якість, експозиція, bloom, світло, сніг, анімація, фізика

## Структура
- `src/main.js` — збирання сцени і головний цикл
- `src/core/` — рендер і постобробка, матеріали, текстури, фізика (cannon-es), гірлянди
- `src/shaders/` — GLSL-шейдери (крига, небо з авророю, сніг, фінальна обробка кадру)
- `src/world/` — ялинка, будиночки, карусель, ковзанка, люди, декор, подарунки/сніговики
- `src/ui.js` — панель налаштувань (lil-gui)
- `public/textures/` — текстури (Poly Haven, CC0)
